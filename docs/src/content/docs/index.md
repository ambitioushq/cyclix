## For people who run Cyclix

- [Guides](/guides/): the steps for a task, such as turning on shell completion.
- [Concepts](/concepts/): how Cyclix works and why.
- [Reference](/reference/): the commands and the config keys, to look up.
- [Patterns](/patterns/): advice on the choices you face when you run Cyclix.

## For people who work on Cyclix's code

- [Design](/design/): how the engine is built, how it is tested, and what the agent and the gate can reach.
- [Architecture decision records](/adr/): one short file for each settled call, with the options that were weighed.
