A pattern page gives advice on a choice you face when you run Cyclix: what to do, why, and when the advice does not apply. Patterns are for people who run Cyclix and set up its tenants. How a feature works is in [Concepts](/concepts/), and the steps for a task are in [Guides](/guides/).
